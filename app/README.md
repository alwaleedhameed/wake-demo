# Wake demo app

React + Vite. See ../RUNBOOK.md for how to run and deploy it.

- `src/App.jsx`: screens, tabs and the shared video player
- `src/components/Feed.jsx`: the vertical feed, captions, Watch/Read/Listen, quiz-and-break card
- `src/components/Onboarding.jsx`: age tiers (EU KIDS Act proposal), EU age-app check, role, interests
- `src/components/Screens.jsx`: Series, Create (verification, two creator routes, studio approval), Me
- `src/data/videos.js`: the demo videos and their real sources
